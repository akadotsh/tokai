# Tokai

Tokai is a terminal interface for inspecting and managing BullMQ queues in Redis.

It lets you view queue and job status, add or remove jobs, and obliterate queues without leaving the terminal.

## Built with

- Bun and TypeScript
- React and OpenTUI
- BullMQ and Redis

## Run locally

```sh
bun install
bun run start
```
